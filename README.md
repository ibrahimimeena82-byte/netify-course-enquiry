# Netify Computer Lab — Course Enquiry Portal (MVP Demo)

## Overview
A mobile-responsive course discovery and enquiry prototype built for a capstone simulation project.

## 3-Step Student Enquiry Flow
1. **Arrive & Scan:** Student lands on the hero banner and clicks **Explore Courses & Enquire**.
2. **Evaluate Course:** Student views the 3 foundational tracks (*Web Development*, *Digital Marketing*, *AI Basics*) and opens **View Syllabus & Details** to check topics and duration.
3. **Enquire:** Student clicks **Enquire via WhatsApp**, launching WhatsApp with a pre-filled course-specific message.

## Out of Scope (Intentional MVP Exclusions)
- Student authentication / user accounts
- Learning Management System (LMS) portals
- Online payment gateways
- Backend database storage of applicant records
